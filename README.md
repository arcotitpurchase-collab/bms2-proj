# Premium Electrical Protection Monitor

A React + Vite implementation based on the supplied reference layout.

## Included functionality

- ON / OFF / TRIP / HEALTHY status cards
- Interactive breaker power toggle
- Interactive Fault / Earth Fault / Short Circuit / Over Current simulation
- Any active protection fault automatically changes breaker state to TRIP
- Reset returns the panel to a healthy ON condition
- EMS / MFM live electrical parameter cards
- Responsive desktop / tablet / mobile layout
- Lucide icons and premium industrial dashboard styling

## Run locally

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```
